# 雷达仿真工作台更新摘要

更新时间：2026-07-23

## 功能更新

- **真实阵列路径求解**：`synthetic_array` 可设为 `false`，支持按实际 Tx/Rx 阵元位置计算路径；开启时仍可使用速度更快的合成阵列近似。
- **三维场景编辑**：方块建筑支持三轴旋转；可导入 OBJ、PLY 模型，并将平移、缩放和旋转写入实际 Sionna/Mitsuba 场景。
- **发射波束配置**：支持相控阵孔径、各向同性、3GPP 单元和自定义增益网格。相控阵可设置行列数、方位/俯仰导向角及 Uniform/Hann 孔径加权。
- **Tx 阵元复权重**：预合成相控阵孔径按行优先顺序输入自定义复权重，原生平面阵列按列优先顺序输入；权重单位范数归一化后进入对应发射处理链路，并提供与 Rx 分离的全宽预览。
- **自定义方向图**：可用 JSON 输入方位角、俯仰角和二维增益矩阵；该方向图进入 Sionna 路径复场计算，不只是界面预览。
- **波束成形结果**：Tx 方向图与 Rx 数字波束形成共同作用于 CIR，并生成相干合成后的路径功率、距离角谱和 FMCW 结果。
- **撤回与重做**：雷达参数和场景几何分别支持最多 50 步撤回/重做；切换方案、结果或保存新版本时自动清空对应历史。

自定义发射增益格式：

```json
{
  "azimuth_deg": [-60, 0, 60],
  "elevation_deg": [-20, 0, 20],
  "gain_db": [[-35, -15, -35], [-18, 12, -18], [-35, -15, -35]],
  "outside_gain_db": -60
}
```

自定义 Tx 复权重格式（数量必须为 `Tx 行数 × Tx 列数`）：

```json
[[1, 0], {"re": 0, "im": -1}, 0.5]
```

## 稳定性更新

- 修复接收导向权重和方向图预览使用行优先顺序、与 Sionna 原始接收通道列优先顺序不一致的问题；自动导向和自定义接收权重现统一采用列优先顺序。
- 新增 `scripts/collect_error_report.sh`，可按 `job_id` 一键收集任务状态、错误堆栈、运行环境和 NPZ 形状清单，同时排除大型数组值、模型文件和环境变量文件。
- 修复工作台阵列配置中的 `gain_grid_json` 被错误传给普通 Sionna `PlanarArray` 方向图工厂的问题；普通 Tx/Rx 阵列会过滤该字段，自定义增益网格模式仍会完成校验并传给对应工厂。
- 修复 `synthetic_array=false` 时把 `Rx 阵元数 × 路径槽数` 误判为路径数、导致 CIR 轴识别失败的问题。逐路径后处理统一使用路径槽维度，完整逐阵元路径元数据另存为 `paths_per_element.npz`，原始 CIR 不做折叠。
- 后处理会自动识别旧版本生成的逐阵元 `paths_summary.npz`：先保留原文件为 `paths_per_element.npz`，再原子生成兼容波束形成、FMCW 和 Web 缓存的逐路径摘要，因此旧失败 run 也可以重新分析。
- 每次仿真使用唯一任务 ID，失败后立即重试不会复用旧目录。
- 失败任务自动清理未完成的 run 和 Web 缓存；多测点任务只保留已经完成的结果。
- 任务状态采用原子文件替换，避免进程中断产生半截 JSON。
- 调度器自身异常也会记录错误并将任务可靠标记为失败，不会长期停在“运行中”。
- 结果索引自动忽略空目录、损坏 CSV、缺少核心文件和无效记录，单个坏结果不会拖垮整个结果库。
- 前端重试会清除旧错误，并阻止上一任务的延迟轮询覆盖新任务状态。
- 新增 Git 完整/增量 bundle 发布流程。目标机更新会校验 checksum、前置版本和提交祖先关系，保留实验数据与环境配置，并在代码切换或健康检查失败时自动恢复旧提交和服务状态。

## 使用边界

- 修改 Tx 方向图、阵列、场景或传播参数后必须重新运行仿真，历史 run 保持不可变。
- `synthetic_array=false` 精度更高，但阵元数较多时显著增加计算量和 CIR 数据量。
- “自定义单元因子”会与阵列因子相乘；兼容模式“自定义总增益（等效 1×1）”直接描述最终发射方向图。两者在界面、配置和结果中分别标注。
- 撤回只作用于尚未保存的编辑，不撤销已提交任务、已保存版本或已经上传的模型文件。

验证：前端生产构建、Sionna RT 2.0.1 实际运行及相关后端单元测试均已通过。

## 2026-08-03 增量更新

- **接收阵元因子**：Rx 方向图导出现在同时保存 `rx_element_pattern.npz` 与 `rx_element_pattern.png`；`rx_steering_pattern.npz` 的阵列响应明确乘入单阵元因子。当前 `iso` 为单位因子，`tr38901` 使用与 Sionna RT 一致的 3GPP 单元模型。
- **CIR 可控噪声**：新增 `cir_noise.enabled`、`cir_noise.snr_db` 和 `cir_noise.seed`。启用后对有效 CIR 复数系数注入可复现的复高斯白噪声，`cir.npz` 保存带噪结果，同时保留 `cir_noiseless.npz`。指标和元数据记录目标SNR、实际SNR、信号功率和噪声功率。
- **场景 JSON 导入导出**：场景几何检查器新增场景 JSON 导入和导出；原有 OBJ/PLY 模型导入保留。JSON 保存地面、建筑中心、尺寸、旋转、材质和模型引用；模型二进制文件仍需通过“导入 3D 模型”单独上传。
- **结果包**：完整结果包新增 `raw/cir_noiseless.npz`、`analysis/rx_element_pattern.npz` 和 `figures/rx_element_pattern.png`；下载目录也提供对应单文件入口。

## 2026-08-04 增量更新

- **发射与接收自定义单元因子**：两端均可在界面选择 `custom_gain_grid`，使用统一的方位角、俯仰角和二维增益 JSON。相控阵发射方向图和接收数字波束方向图都会实际乘入自定义单元因子。
- **显式模式区分**：发射端将“相控阵孔径”和旧版“自定义总增益（等效 1×1）”分别显示；前者按单元因子乘阵列因子计算，后者直接替代完整发射方向图。
- **即时格式校验**：前端显示网格尺寸或具体错误，并在格式无效时禁止提交；后端重复执行相同的结构、有限数值、尺寸和等间隔校验。
- **配置完整往返**：实验方案、运行请求和 `config.yaml` 保存发射 `element_pattern`、`element_gain_grid_json` 以及接收 `gain_grid_json`，重新打开后不会退回预设方向图。
- **显式参数保存**：雷达参数面板新增“保存参数”，将自定义单元因子及其余雷达配置写回当前实验方案；保存成功后基线和撤回历史同步更新，历史仿真结果不变。
- **结果可追溯**：新增 `tx_element_pattern.npz/png`，现有发射合成方向图与接收单元/合成方向图均保存所用模式和原始自定义网格；下载目录和结果包提供全部文件。
- **便携场景源码包**：源码打包脚本新增 `--with-experiment`，可只携带一个完整实验方案及去除绝对路径的 `scene_import.json`，不附带大型历史结果；压缩包同步生成 SHA-256 校验文件。
